# Rama Devi - Senior .NET Full Stack Developer Portfolio

A ultra-modern, "super UI rich" developer portfolio website engineered for **Rama Devi**, Senior .NET Full Stack Developer & Enterprise Cloud Architect.

## 🌟 Highlights & Features

- **Cyber-Modern Glassmorphic Dark UI**: Deep space dark mode with animated backdrop blur, ambient neon glows, and custom typography (`Plus Jakarta Sans`, `Outfit`, `JetBrains Mono`).
- **Interactive Constellation Canvas**: Particle network responding to mouse movement in real time.
- **Dynamic Role Typer**: Smoothly rotating professional titles emphasizing .NET 10, Cloud Microservices, and AI Copilot integration.
- **Theme Palette Switcher**: Real-time accent color switches (Cyber Cyan, Electric Violet, Matrix Emerald, Amber Flare) with persistent `localStorage`.
- **Audio Feedback**: Subtle sci-fi synthesized sound effects using the Web Audio API (toggleable).
- **Interactive System Architecture Explorer**: Visual flow diagrams and architectural deep-dives for:
  1. *CVS Health*: Modern .NET 10 & EventBridge FHIR Pipeline
  2. *Microsoft*: Purview Data Classification Service & Flighting Platform
  3. *LACOE*: Statewide Education Data Exchange Layer
- **Interactive Skills Matrix**: Filterable grid by category (.NET Backend, Cloud & DevOps, Frontend UI, Databases, Testing & Architecture) with animated proficiency indicators.
- **Experience Timeline**: Career trajectory spanning Aetna/CVS Health, Microsoft, LACOE, Nationwide, eBay, Progressive, and Bartronics.
- **Case Study Modals**: In-depth architecture overviews with business challenges, technical solutions, and impact metrics.
- **Interactive Developer CLI Sandbox**: In-browser PowerShell-style command terminal with command history and clickable shortcuts (`whoami`, `skills`, `experience`, `architecture`, `stats`, `contact`).
- **One-Click Clean Resume Print / PDF Export**: Styled with `@media print` rules for an executive-ready printable resume.
- **Zero External Runtime Dependencies**: Standalone HTML5, CSS3, and modern vanilla JavaScript that runs directly from disk or any web server.
